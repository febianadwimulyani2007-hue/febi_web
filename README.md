# Situs Sederhana — Febiana Dwi Mulyani

Situs statis sederhana dengan nama di pojok kiri atas dan perbandingan fitur hosting.

Cara menjalankan secara lokal:

```bash
cd /workspaces/febi_web
python3 -m http.server 8000
# lalu buka http://localhost:8000
```

Cara deploy ke GitHub Pages:

1. Buat repository di GitHub.
2. Push semua file ke branch `main` atau `gh-pages`.
3. Aktifkan GitHub Pages di pengaturan repository (Source: `main` / `gh-pages`).

Atau deploy ke hosting tradisional dengan FTP/cPanel: unggah isi folder ke public_html.
